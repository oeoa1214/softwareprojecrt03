홍정현 파트 파일별 설명 (1주차 제출)
====================================

데이터가 흐르는 순서대로 설명한다.
표준노드링크(SHP) -> [1] 변환 -> CSV -> [2] RoadApi -> [3] Crossroad / [4] ShortestRoad -> 병원 비교 결과

------------------------------------------------------------
1. convert_standard_nodelink.py  (표준노드링크 자르기)
------------------------------------------------------------
- 하는 일: 전국 표준노드링크(SHP)에서 대구(군위 제외)의 교차로와 도로 구간만 골라 CSV 두 개로 저장한다. (계획서 IF-003, AD-08)
- 입력: MOCT_NODE.shp, MOCT_LINK.shp
- 출력: data/node.csv, data/link.csv
- 핵심 동작
  1. NODE_ID, LINK_ID의 앞 3자리가 150~157인 것만 남긴다. (군위는 제외)
     지역 번호 칸(STNL_REG)이 파일에 있으면 그 값을 쓴다.
  2. 도로 구간은 출발·도착 교차로가 둘 다 남은 것만 남긴다. (한쪽이라도 없으면 끊긴 길)
  3. 좌표는 EPSG:5186(미터)에서 위도·경도(EPSG:4326)로 바꾼다.
  4. 끝에 확인 결과(개수, 좌표 3개, 끊긴 길 수)를 출력한다. 이 화면이 제출용 캡처다.
- 실행: python convert_standard_nodelink.py MOCT_NODE.shp MOCT_LINK.shp
- 실행 결과: 교차로 28,441개, 도로 구간 40,914개, 끊긴 길 0개
- 주의: 프로그램이 돌 때 쓰는 파일이 아니라, 처음 한 번 CSV를 만드는 준비용 파일이다. pyshp, pyproj가 필요하다.

------------------------------------------------------------
2. data/  (CSV 파일 4개)
------------------------------------------------------------
- node.csv, link.csv: 위 1번이 만든 진짜 대구 데이터.
    node.csv 칸: node_id, node_name, lat, lon
    link.csv 칸: link_id, f_node_id, t_node_id, length_m, max_spd
- dummy_node.csv, dummy_link.csv: 진짜 파일을 못 읽을 때 대신 쓰는 작은 가짜 데이터. (교차로 5개, 도로 6개)

------------------------------------------------------------
3. road_api.py  (RoadApi: 표준노드링크 읽기)
------------------------------------------------------------
- 하는 일: 위 CSV를 읽어 리스트로 돌려준다.
- 메소드: load_node_link() -> (nodes, links, is_dummy)
    nodes = [(node_id:int, node_name, lat:float, lon:float), ...]
    links = [(link_id:int, f_node_id:int, t_node_id:int, length_m:float, max_spd:int), ...]
    파일이 없거나, 비었거나, 숫자가 잘못되면 더미 CSV로 읽고 is_dummy=True로 알려준다.
- 조립할 때: main.py가 is_dummy를 보고 EX-03 메시지를 띄운다. DB에 저장하는 건 Repository(오은찬)다.
  도로 속도 메소드는 오은찬이 같은 클래스에 추가한다.

------------------------------------------------------------
4. crossroad.py  (Crossroad: 사고 지점 -> 가장 가까운 교차로)
------------------------------------------------------------
- 하는 일: 클릭한 위도·경도에서 300m 이내 가장 가까운 교차로 번호를 찾는다. (AD-04)
- 만드는 법: Crossroad(nodes), nodes는 [(node_id, lat, lon), ...]
- 메소드: find_crossroad(lat, lon)
    대구 범위(교차로 위도·경도의 최소~최대) 밖이면 -1
    가장 가까운 교차로가 300m 초과면 -2
    300m 이내면 교차로 번호(int). 300m 딱 맞으면 정상이다.
    내부의 __distance는 하버사인 공식(지구 반지름 6371000m)으로 거리를 잰다.
- 조립할 때: Ui(오은찬)가 -1, -2를 보고 EX-04, EX-05 메시지를 띄운다. Crossroad는 메시지를 직접 띄우지 않는다.

------------------------------------------------------------
5. shortest_road.py  (ShortestRoad: 최단 시간 경로 + 병원 비교)
------------------------------------------------------------
- 하는 일: 사고 교차로에서 각 병원까지 가장 빨리 가는 시간과 경로를 구해 도착 시간 순으로 정렬한다. (AD-02, AD-05, AD-07, FR-01)
- 만드는 법: ShortestRoad(links, speeds), speeds는 [(link_id, 속도km/h), ...]
    속도가 없는 도로는 제한 속도(max_spd)를 쓴다.
    속도가 1~150km/h 밖인 도로는 그래프에 넣지 않는다.
- 메소드
    passway_time(length, speed): 통행 시간(초) = 길이(m) / (속도 x 1000 / 3600). 600m, 36km/h면 60초.
    dijkstra(start): 최소 힙(heapq)으로 사고 교차로에서 모든 교차로까지 최소 시간(초)을 구해 {교차로: 시간}으로 돌려준다.
    sort_hospitals(hospitals): 입력 [(hpid, name, node_id, beds)]
        -> 출력 [(hpid, name, beds, eta_min, distance_m, node_count)]
        도착 시간 순이고, 병상 0 이하·None은 맨 뒤다. 갈 수 없는 병원은 뺀다. dijkstra를 먼저 불러야 한다.
    make_route(hospital_node): [사고 교차로, ..., 병원 교차로] 순서의 교차로 번호 목록.
- 조립할 때: 오은찬이 DB에서 꺼낸 links와 속도(같은 번호는 평균 낸 값)를 넘긴다.

------------------------------------------------------------
6. check_linkspeed.py  (교통 API 응답 확인)
------------------------------------------------------------
- 하는 일: linkspeed.json(대구 교통소통정보 API 응답 저장 파일)으로 두 가지를 확인한다.
    ① 응답의 도로 구간 번호(STD_LINK_ID)가 link.csv의 link_id와 몇 개 맞는지 센다.
       거의 안 맞으면 자르기나 번호 읽기가 틀린 것이다.
    ② 응답의 속도로 ShortestRoad를 돌려 대구 전체에서도 오류 없이 병원 경로가 나오는지 본다.
- 실행: python check_linkspeed.py linkspeed.json
- 실행 결과: 서로 다른 번호 4805개 중 4723개(98.3%)가 link.csv에 있다.
             사고 교차로에서 닿는 교차로 27,169개 / 전체 28,441개. 병원 경로 오류 없이 계산됨.
- 참고: 같은 번호가 여러 번 나와도 고치지 않고 그대로 넣는다. 평균은 오은찬이 만든다.
        이 스크립트도 제출용 캡처를 찍기 위한 확인 파일이다.

------------------------------------------------------------
- test_road_api.py: 정상 읽기, 파일 없음/깨짐/빈 파일이면 더미로 대체 (TE-24, TE-25)
- test_crossroad.py: 100m 이내 정상, 0m·300m·300.1m 경계값, 대구 밖 (TE-09, TE-10, TE-11, 3.5.2 1번)
- test_shortest_road.py: 통행 시간 60초, 최소 힙 순서, 더 빠른 경로 선택, 병상 0 맨 뒤, 속도 경계값
                         (3.4.3 ①~④, TE-14, 3.5.2 2~4번)
- test_linkspeed.py: linkspeed.json 읽기, 번호 대조, 중복 번호 (도로 속도 테스트 안내)
- 실행: python -m pytest tests -v  ->  25 passed 가 나오면 통과다. 이 화면이 제출용 캡처다.
